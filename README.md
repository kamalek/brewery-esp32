# Пивоварня на ESP32

Автоматизация пивоварни на ESP32: контроль температуры, насосы и веб-интерфейс.
Проект с открытым исходным кодом — схемы и прошивки в этом репозитории.

## Возможности
- Контроль температуры затора и кипячения
- Управление ТЭН/насосом через реле
- Веб-интерфейс с текущими показаниями

## Структура проекта
- `firmware/` — прошивка для ESP32 (Arduino IDE)
- `hardware/` — схемы и платы
- `docs/` — сайт проекта (GitHub Pages)

## Быстрый старт
1. Соберите электронику по схеме из папки `hardware/`.
2. Откройте `firmware/brewery/brewery.ino` в Arduino IDE.
3. Впишите в скетче имя и пароль своей Wi-Fi сети.
4. Прошейте ESP32 и откройте IP-адрес платы в браузере.
